# Contributing to Internet Magazin Frontend

We love your input! We want to make contributing as easy and transparent as possible.

## Development process

1. Fork the repo and create your branch from `main`.
2. Run `npm install`.
3. Make your changes, add tests for new features.
4. Run linters: `npm run lint`
5. Ensure all tests pass: `npm test`
6. Push to your fork and submit a Pull Request.

## Code style

- Follow official [Angular Style Guide](https://angular.dev/style-guide)
- Use standalone components, inject() over constructor injection
- Use Signals for state where appropriate

## Commit messages

We follow [Conventional Commits](https://www.conventionalcommits.org/):
- `feat:` new feature
- `fix:` bug fix
- `docs:` documentation only
- `refactor:` code change that neither fixes a bug nor adds a feature
